📱 MATH GAME – ONLINE & OFFLINE

A fast-paced, brain-training game designed for Android (landscape mode), built to improve mental math skills in a fun and engaging way.

Developed independently over six months, this game evolved from a weekend project into a fully-featured mobile experience with multiple updates and improvements.

✅ Designed for fast calculations

🏡 Each correct answer builds your house in game

🎮 Multiple fun and challenging game modes

🌍 Multiplayer supported

🌐 Available in multiple languages

🛠️ UI/UX designed in-house, with custom artwork by a freelance designer

🧠 Helps improve focus and calculation speed

🎲 Fruit Game 🍉

Solve 3-equation puzzles where the first two establish fruit-to-number relations.

The third equation is missing a value, and you must choose the correct option.

Difficulty increases with each correct answer.

🏡 Build Interactable 3D House

Build and rotate your custom house by swiping the screen.

🔥 Rapid Fire

Answer as many simple equations as possible within a set time.

Difficulty remains constant.

Choose difficulty level and timer duration before starting.

🌍 Multiplayer Mode

Connect and play with others globally by creating or joining a room using a Room ID.

Includes in-game chat (implemented using Unity networking and RPCs).

Each room supports one creator and one joiner.

✏️ Complete the Equation

Similar to Rapid Fire, but one number in each equation is missing.

Choose the correct option to complete the equation.

♾️ Endless Mode

Like Rapid Fire, but no timer.

Ideal for long, relaxed gameplay.

Equation difficulty increases with each answer.

🧩 Hint System

50/50 Hint: Removes two incorrect options.

Smart Hint: Replaces the equation with a simpler one.

Earn hints in the shop or watch rewarded ads to use hints when out.

🎁 Daily Reward System

Encourages daily engagement with free rewards.

Claim rewards daily to progress, and unlock new houses at the end of the week.

A popup shows rewards available for each day.

🌐 Multi-Language Support

Supports Arabic, Hindi, and more.

Uses a custom-built lightweight language system for minimal memory usage.

Only the active language is loaded for better performance.

View implementation in the shared source code.

🛒 Shop

Buy themes, houses, and hints using in-game currency or via daily rewards.

Remove Ads in-app purchase available from the home screen.

👤 Player Profile

Track total games played, wins, and losses.

Monitor your progress and improvement over time.

📜 Game Rules

Learn each game mode through an easy-to-understand rules system.
