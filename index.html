Project Overview

What started out as a targeted weekend design experiment evolved into a fully-featured standalone production deployment with custom artwork integration, state serialization, and global room connectivity.

🍓 1. Fruit Game Mode

Solve dynamic 3-equation logic puzzles where operators and icons establish quantitative relationships before answering the final variable.

  • Difficulty values auto-scale gracefully with every perfect computation streak.
  • Success feeds into an idle-progression mechanic where player correct runs actively build and rotate unique player properties via screen swipes.

🔥 2. Rapid Fire Mode

Test processing speeds by accurately completing as many simple numeric formulas as possible before the clock expires.

  • Configurable session conditions: Custom Question Length, Number of Digits, and Timer durations before initiation.

🌐 3. Multiplayer Matchmaking Mode

Allows participants to cross-connect globally to compete in unified challenge spaces inside shared session instances.

  • Streamlined 2-player lobby setup supporting independent match host generation and direct Room ID handshakes.
  • Integrated live real-time interaction systems handling textual communications cleanly across players during active play.

✏️ 4. Complete the Equation Mode

A fast-paced structural twist on traditional time-attack calculation runs where missing operators/operands must be discovered contextually.

♾️ 5. Endless Endurance Mode

A pure tracking framework with zero active time counters designed for high-streak retention loops where any single computational error triggers a run-loss condition.

📡 Network Infrastructure

Realized global multi-room operations safely using specialized remote invocation architecture patterns:

  • Unity Networking & RPCs: Handles instantaneous gameplay state mutations and text chat updates securely between room creator and joiner nodes.

🌍 Memory-Optimized Localization

Built an in-house custom translation router handling Arabic, Hindi, Filipino, and English seamlessly:

  • Dynamic Asset Streaming: Only loads string arrays for the actively selected profile language, minimizing runtime memory footprint and allocation spikes.

💡 Tactical Utility Subsystems

  • 50/50 Hint Module: Programs programmatic parsing routines to drop two bad variable buttons cleanly from UI canvas view upon input invocation.
  • Smart Hint Router: Contextually swaps highly nested mathematical strings for clear, basic algebraic equivalents mid-run to assist target focus retention.
  • Daily Reward System: Drives customer monetization and retention loops through automated 7-day calendar claims, unlocking new home asset structures.
