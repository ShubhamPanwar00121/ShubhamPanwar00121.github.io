2️⃣ War Tank

Role: Solo Developer

Platform: Android

Overview

War Tank is a fast-paced action defense game where the player controls a tank to destroy incoming enemy bombs.

Developed entirely by me, this project was selected for the Google Indie Developer Program, where Google provided direct support and feedback to improve the game.

🛠️ Features Implemented

🛠️ Tank Unlock & Upgrade System

⚡ Power-Up System

Power-Up 1: Freezes all enemies temporarily

Power-Up 2: Shield around the player

Power-Up 3: Multiplies bullets fired

💣 Enemy Bomb Mechanics

Uses object pooling for performance.

Large bombs split into smaller bombs when hit.

🚁 Boss Levels

Every 5th level introduces a helicopter boss fight with animated timed bombs.

This project highlights my expertise in gameplay mechanics, performance optimization, and engaging enemy systems.
