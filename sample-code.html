🛒 SHOPPING LIST HELPER

Windows Console C++ OOP File Handling
💻 Source Code

Platform: Windows Console (C++)

Type: Console Application

Objective: Practice and demonstrate core OOP concepts in C++.

🧠 Overview

Shopping List Helper is a text-based console application developed in C++ to showcase Object-Oriented Programming principles such as classes, encapsulation, inheritance, and file handling.

This utility simulates a guided shopping experience where the user navigates through shop categories, selects items, and generates a complete shopping bill saved as a .txt file.

🛠️ Features

  • Genre-based shopping (Dairy, Grocery, Medical)
  • Dynamic list of shops under each genre
  • Real-time stock and quantity tracking
  • Seamless item selection and quantity input
  • Purchase summary saved to a text file
  • Interactive CLI-based user flow

📋 How to Use

  1. Locate the .exe file inside the build folder from the source code.
  2. Run the .exe — the program starts by asking for your shopping genre (dairy, medical, grocery).
  3. Choose a shop from the displayed list by entering its number (e.g., 1).
  4. View the list of available commodities in that shop.
  5. Enter the item name (e.g., milk) you want to buy.
  6. The system shows the available quantity (e.g., 112 liters). Enter how much you want to purchase.
  7. Your item is added to the shopping list. You can continue shopping or type exit.
  8. Repeat the process across different shops as needed.
  9. Once finished, exit to main menu. The app generates a text file summary.
  10. Sample output generated by the application.

🧠 UNITY DEMO CODE & UI OVERVIEW

Unity C# Android UI Systems Algorithms
💻 Source Code

This Unity project showcases a set of features implemented across three key scenes: Daily Reward, Leaderboard, and Algorithm.

Built for Android portrait mode and optimized for both phones and tablets.

🎁 1️⃣ Daily Reward System – UI & Logic

Scene Name: DailyReward_Scene

UI optimized for portrait mode across phones and tablets.

Anti-Cheating Logic

  • Fetches real-time data from public API
  • Displays "No Internet!" if offline
  • Falls back to device time if API fails
  • 2-second timeout limit

Reward System

  • Daily rewards upon app open
  • 7-day reward cycle
  • Special reward at cycle completion
  • Automatic reset after 7 days

Test Mode

  • Live Mode = 24 hours
  • Test Mode = 4 seconds
  • Restart required for changes

Data is loaded from JSON in the Resources folder and designed for easy migration to Remote Config.

Efficient rendering using only 6 draw calls and compressed textures.

🏆 2️⃣ Leaderboard System

Scene Name: LeaderBoard_Scene

  • Displays 30 randomly generated players
  • Uses object pooling for performance
  • Smooth scrolling UI
  • Real-time score update system

Users can update a player’s score through a debug panel.

➕ 3️⃣ Algorithm – Three Pair Sum

Scene Name: Algorithm_Scene

  • User inputs comma-separated values
  • Checks if any 3 numbers match target sum
  • Single script: CheckIntegerSum
  • Interactive UI system

Demonstrates a core algorithm implemented in Unity with dynamic input handling.
